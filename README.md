# E-Commerce Sales & Customer Analytics

## Overview
End-to-end analysis of e-commerce order, customer, payment, and review data to evaluate business performance. Results are presented in an interactive Power BI dashboard.

**Tools:** MySQL, Excel, Power BI

## Objectives
- Analyze sales trends and order statuses
- Understand customer distribution and payment methods
- Evaluate customer review scores
- Present business insights through an interactive dashboard

## Approach
1. **Data quality checks:** identified duplicate records, missing values, and unmatched order records
2. **SQL analysis:** used joins, aggregate functions, CTEs, subqueries, and window functions to analyze business performance
3. **Dashboard:** built an interactive Power BI dashboard with KPI cards, charts, and monthly order trends

## Skills Demonstrated
SQL (MySQL), data cleaning and validation, data analysis, data visualization, Power BI, Excel
